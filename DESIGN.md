# Kriterion Academic — Design System & Visual Authority (Anti-Slop)

## 1. Aesthetic Direction & Design Read
- **Design Read:** High-precision Swiss Editorial Instrument & Academic Preflight Suite for discerning scholars.
- **Dials:**
  - `DESIGN_VARIANCE: 7` (Intentional asymmetry, non-uniform rhythm, rejecting the 3-box AI grid).
  - `MOTION_INTENSITY: 5` (Restrained, physical, high-friction spring dynamics; Emil Kowalski style).
  - `VISUAL_DENSITY: 5` (Balanced between editorial breathing room and high-information scientific instrumentation).

## 2. Anti-AI Slop Mandate (Strict Bans)
- **NO Purple/Blue/Cyan Neon Mesh Gradients:** Replaced with warm, physical paper tones, subtle slate borders, and purposeful amber/emerald semantic indicators.
- **NO Uniform Cloned Card Grids:** No 3 identical rounded rectangles lined up with icons. Hierarchy must be asymmetrical and editorial.
- **NO Raw Emojis as UI Controls:** All iconography must be bespoke, crisp SVG vectors with uniform stroke weight (1.5px to 2px).
- **NO Generic Pure-Inter Typography:** Expressive typographic pairing: Editorial Serif headers (`Instrument Serif` / `Newsreader` / `Playfair`) paired with high-legibility geometric/neo-grotesque body (`Plus Jakarta Sans` / `Geist` / `-apple-system`) and engineering monospace (`JetBrains Mono` / `SF Mono`) for metrics, digests, and hashes.

## 3. Color Tokens
- **Backgrounds:**
  - Surface Main: `#090d16` (Deep Obsidian Ink)
  - Surface Raised: `#111827` (Card / Metric Panel)
  - Surface Border: `rgba(255, 255, 255, 0.08)`
  - Surface Accent Tint: `rgba(99, 102, 241, 0.08)`
- **Accents:**
  - Academic Amber (Alerts / Warnings): `#f59e0b`
  - Emerald Verified (Clean / High Purity): `#10b981`
  - Indigo / Slate Primary: `#6366f1` / `#94a3b8`

## 4. Motion & Micro-Interactions (Emil Kowalski Philosophy)
- **Springs over Easing:** `cubic-bezier(0.16, 1, 0.3, 1)` for snappy, physical arrival without rubber-band wobble.
- **Spatial Consistency:** Elements move with purpose; modals expand from the trigger origin; toast notifications exit seamlessly without layout shifts.
- **Feedback:** Subtle tactile state changes (scale: `0.98` on click, slight border illumination on hover).
