Esta guía es una propuesta de revisión, no una escala académica validada. Ajústala a la rúbrica del docente. El índice de estilo de Zero-IA no debe convertirse en nota ni en prueba de autoría.

## Procedimiento

1. Conserva el original y registra versión, fecha y nombre del revisor.
2. Comprueba que el texto extraído conserva párrafos, tablas y bibliografía; si falta contenido, no evalúes esa sección automáticamente.
3. Ejecuta la revisión y guarda el informe. Anota si trabajaste en navegador o Streamlit.
4. Revisa cada observación bibliográfica contra la fuente original. Registra título, autor, fecha, DOI/enlace, página o pasaje y la afirmación que sostiene. Marca «no comprobada» si no pudiste consultarla.
5. Usa la legibilidad para localizar pasajes difíciles. No sustituyas precisión conceptual por palabras largas ni penalices la claridad.
6. Acuerda las correcciones con el autor, conserva evidencias y revisa la versión corregida.

## Rúbrica propuesta

Usa 0 = ausente, 1 = insuficiente, 2 = adecuado, 3 = sólido. «No evaluable» es distinto de 0. Acompaña cada puntuación de una evidencia y una acción concreta. No sumes una nota final sin acordar pesos y criterios con el docente.

| Criterio | Qué comprobar | Puntuación / evidencia / acción |
|---|---|---|
| Pregunta y objetivos | Problema delimitado, objetivos coherentes y alcance explícito. | |
| Argumentación | Cada conclusión se deriva de resultados o fuentes; distingue hechos e interpretación. | |
| Método | Procedimiento reproducible, datos apropiados y limitaciones reconocidas. | |
| Evidencia | Afirmaciones relevantes respaldadas por fuentes pertinentes y consultadas. | |
| Referencias | Citas y bibliografía corresponden; metadatos comprobados; formato consistente. | |
| Claridad | Términos definidos, oraciones comprensibles y párrafos con función clara. | |
| Aporte | Análisis propio, comparación crítica y explicación del valor del trabajo. | |
| Presentación | Tablas, figuras, anexos, unidades y numeración consistentes. | |
| Transparencia | Se declara el uso de herramientas conforme a la política de la asignatura. | |
